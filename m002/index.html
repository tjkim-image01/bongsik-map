공유기(Wi-Fi) IP같은 Wi-Fi 접속용

같은 와이파이나 공유기에 연결된 스마트폰, 노트북, 태블릿에서 바로 접속할 수 있어요.

퍼블릭(공인) IP외부 인터넷 접속용

집 밖이나 LTE/5G 모바일 데이터를 쓰는 다른 사람에게 보낼 주소예요.

퍼블릭 IP 오픈(외부 접속 허용) 방법 안내
  1. 공유기 관리자 접속: 브라우저로 http://192.168.0.1 (또는 192.168.1.1)에 접속합니다.
  2. 포트포워딩 설정:
    • 내부 IP: 192.168.75.32
    • 외부/내부 포트: 4400, 프로토콜: TCP 추가 후 저장
  3. 맥 방화벽 허용: 시스템 설정 → 네트워크 → 방화벽에서 들어오는 연결을 허용합니다.
  4. 간편 대안: 터미널에서 cloudflared tunnel --url http://localhost:4400 실행 시 공유기 설정 없이 전 세계 누구나 접속 가능한 보안 HTTPS 주소가 즉시 열립니다.

왼쪽 아래에서 내 눈높이와 주인공 모드를 선택할 수 있어요. 주인공 모드는 캐릭터 뒤를 따라가는 시점이며, 오른쪽 캐릭터 동작에서 걷기·인사·춤을 실행하고 다른 사람에게도 그대로 보여요. 관전 모드를 누르면 소유 앞 관람 자리로 걸어가고, 왼쪽 소유 플레이와 POV 플레이를 누르면 방 전체에서 함께 감상할 수 있어요. 아직 POV 영상을 내려받는 사람이 있으면 다운로드 진행률(%)이 표시되고, 모두 다 받으면 같은 지점부터 함께 재생됩니다.
